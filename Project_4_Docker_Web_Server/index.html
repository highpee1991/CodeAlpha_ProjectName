CloudOps Web Server

A simple web server deployed inside a Docker container.

This project demonstrates how to package a web server using Docker, run it as a container, expose it to the browser, and monitor its health.

View Project Docker Workflow 
$ docker build -t cloudops-web .
$ docker run -d --name cloudops \
    -p 8080:80 cloudops-web
$ docker ps
cloudops   Up 12s (healthy)   0.0.0.0:8080->80/tcp

Project overview

Three ideas make up this deployment.

Containerization

The website is packaged into a Docker image and runs inside an isolated container.

Web Server

Nginx serves the website and makes it accessible through a mapped host port.

Health Monitoring

Docker health checks help verify whether the web server is responding correctly.

Docker workflow

From files on disk to a page in the browser, in five steps.

  1. 1

    Website Files

    The index.html and styles.css files that make up the site.

  2. 2

    Docker Image

    A Dockerfile copies the files into an Nginx image, a read-only template.

  3. 3

    Docker Container

    Running the image starts a container, an isolated instance of it.

  4. 4

    Nginx Web Server

    Nginx inside the container listens on port 80 and serves the files.

  5. 5

    Browser

    Host port 8080 maps to the container, so the site opens at localhost:8080.
